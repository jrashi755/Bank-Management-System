# Bank-Management-System
A java-based desktop application for managing basic banking operations using Java, Swing, JDBC, and MySQL.

## Features

- User Login
- Customer Management
- Account Management
- Banking Operations
- MySQL Database Integration
- Customer Rating System

- ## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- NetBeans/ VS Code
- Git & GitHub

- ## Database

- The application uses MySQL to store and manage data.
- Database schema:
- [database schema.txt](https://github.com/user-attachments/files/30854053/database.schema.txt)

  ## How to Run

  1. Clone this repository.
  2. Open the project in an IDE.
  3. Configure the MySQL database.
  4. Add the MySQL Connector/J library.
  5. Run the main Java class.
